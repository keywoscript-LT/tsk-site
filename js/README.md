# TSK Esports — структура сайта

Залить содержимое папки в корень сайта рядом с уже существующими `tw.css`, `brawlers.js`, `brawlers-local.js`, `sw.js`, `img/logo.png` и т.д. (они не менялись).

- `index.html` — оболочка (12 КБ): метатеги, разметка, загрузчик.
- `css/` — 10 файлов стилей (порядок подключения = порядок каскада, задан в index.html).
- `js/` — 54 модуля. Выполняются строго подряд в порядке списка `TSK_FILES` (в head index.html): сначала ядро `app-*.js`, потом слои `*-view.js` и т.д., которые переопределяют ранние функции.
- `lang/` — 10 языковых пакетов (pl de es pt fr it tr ja ko zh), грузятся только когда язык выбран.
- `img/bc/` — картинки battle-карточек (раньше были base64 внутри JS, 238 КБ).

Скрипты скачиваются параллельно (запрос стартует в `<head>`), а исполняются одним куском — как раньше inline. Поэтому порядок в `TSK_FILES` менять нельзя.

Новый модуль: положить файл в `js/` и добавить `["js/имя.js"]` в `TSK_FILES` на нужное место.

После правок поднимай `TSK_V` в index.html (`window.TSK_V='1'`), чтобы браузеры не держали старые файлы.
